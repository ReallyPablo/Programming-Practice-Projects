Чому клітинка ember – це std::uint8_t, а не int:
Клітинка пам'яті в ember має зберігати рівно один байт (8 біт) зі значеннями від 0 до 255. Тип std::uint8_t гарантовано займає 1 байт на будь-якій системі. А int залежить від архітектури (зазвичай 4 байти - 32 біта).


Захист:
1. Що робить компілятор? Назвіть одну помилку, яку він ловить, і одну, яку ні.
Комп'ютер перекладає код на C++ у машинний код з нулів та одиниць, який розуміє процесор. Він піймаєу помилку, наприклад якщо забути (;). Але не замітить, якщо замість додавання буде віднімання.
2. Чому sizeof різний на різних машинах? А що лишається однаковим, якщо взяти std::uint8_t?
Тому що, в різних системах або 32, або 64 біти, ізза чого може відрізнятися. Але std::uint8_t завжди має розмір 8 бітів.
3. Чому знакове переповнення невизначене, а беззнакове загортання - ні? Що з цього мають використовувати байти ember і чому?
Бо для беззнакових типів в стандарті чітко сказано, що після 255 йде 0. А для знакових це невизначена поведінка, бо від'ємні числа зберігаються по-різному на різних процесорах. Пам'ять в Ember використовує беззнакове загортання, просто показує байти пам'яті від 0 до 255.
4. Чому 0.1 + 0.2 не дорівнює 0.3? Коли величину варто тримати в int, а не у float?
Тому що, комп'ютер зберігає дроби в двійковій системі і не може точно записати 0.1 чи 0.2 (дроби у двійковій системі за стандартом IEEE 754 зберігаються неідеально, бо виникає похибка), int варто використовувати для точних речей, де похибки в округленні неприпустимі.
5. Біти 01000001 – назвіть три типи, якими їх можна прочитати, і що ви «побачите» кожним.
01000001 - якщо це символ A, тому що в uint8_t це число 65. (bool буде true)
6. Чим літерал відрізняється від const і від змінної? Навіщо ініціалізувати?
Літерал - це число або символ. const - це змінна яку не можна змінити. А в звичайній змінній значення можна змінити. Ініціалізувати їх потрібно для того, щоб у пам'яті не залишалося сміття від інших програм. Щоб не було багів і прорблем.
7. Що вам дає AddressSanitizer такого, чого не дає тест «ну, надрукувало 42»?
AddressSanitizer знаходить небезпечні витоки та виходи за межі масиву, а звичайний друк може просто випадково спрацювати й приховати критичну помилку.
8. Який рядок у main.cpp вирішує, яка команда виконається? Що станеться з командою, якої ви його не навчили?
if / else if - ці блоки вирішують яку команду виконувати, якщо ввести команду яку він не знає, спрацює else і виведеться помилка про unknown command.
